# Changelog

All notable changes to Mock Wallet will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-17

### Added
- 🎉 Initial release of Mock Wallet
- 💼 Multi-account wallet management with drag-and-drop reordering
- 🔗 WalletConnect v2 integration with Reown
- 👁️ Watch-only address support
- 📥 Import wallets via private key, mnemonic, or address
- 📤 CSV bulk import/export functionality
- 🌐 Multi-chain support (Ethereum, Polygon, Arbitrum, Optimism, Base)
- 🔄 Automatic account switching with WalletConnect session updates
- 📱 Progressive Web App (PWA) support
- 🎨 Brutalist design with dark mode
- ⚡ Next.js 15 with App Router
- 🔐 HD wallet support with BIP-39 mnemonics
- 💾 Local storage persistence
- 📊 Real-time balance updates
- 🔄 Transaction history tracking
- 🌍 URL parameter import for CI/CD workflows
- 📝 Comprehensive documentation

### SEO & Performance
- 🚀 Comprehensive SEO optimization
- 📱 Mobile-first responsive design
- ⚡ Performance optimizations (LCP, FID, CLS)
- 🔍 Structured data with JSON-LD
- 🖼️ Open Graph and Twitter Card metadata
- 🗺️ Dynamic sitemap generation
- 🤖 Robots.txt configuration
- 🔒 Security headers
- 📦 PWA manifest
- 🌐 Multi-language preparation

### Technical
- TypeScript for type safety
- ethers.js v6 for Web3 interactions
- @dnd-kit for drag-and-drop functionality
- Radix UI for accessible components
- Tailwind CSS v4 for styling
- Bun for fast package management
- Vercel Analytics integration

### Documentation
- Comprehensive README with usage guide
- SEO strategy document
- Contributing guidelines
- Security policy
- Humans.txt
- Well-known directory setup

## Version History

### Version Naming
- **Major** (X.0.0): Breaking changes
- **Minor** (0.X.0): New features, backward compatible
- **Patch** (0.0.X): Bug fixes and improvements

### Support
- **Latest Version**: Fully supported
- **Previous Major**: Security updates only
- **Older Versions**: No support
